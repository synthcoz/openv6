Before you can use IPv6 proxies, or run your own, your connection needs IPv6. Most large ISPs and almost every VPS provider enable it today, but plenty of routers still ship with it switched off. Here is how to check in two minutes.

The 10-second test

Open a terminal (PowerShell on Windows) and run:

curl -6 https://api6.ipify.org

If it prints an address like 2001:db8:51c0:1e::a41f, you have working IPv6. An error such as "Couldn't connect" or "Could not resolve host" means no IPv6 route to the internet. (On Windows, use curl.exe if curl is mapped to PowerShell's own command.)

Prefer a website? Open test-ipv6.com in a browser with any VPN turned off.

Windows

ipconfig

Under your active adapter, look for IPv6 Address or Temporary IPv6 Address starting with 2 or 3. A line that only says Link-local IPv6 Address . . . : fe80::… does not count.

macOS

ifconfig | grep "inet6 2"

Or open System Settings → Network → (your connection) → Details → TCP/IP and check the IPv6 address and prefix length. Set "Configure IPv6" to Automatically if it is off.

Linux

ip -6 addr show scope global

A good result contains a line like inet6 2001:db8:51c0:1e:…/64 scope global dynamic mngtmpaddr. The /64 is your prefix length; mngtmpaddr and dynamic mean the address was assigned automatically from the router's /64.

Also check that there is a default route:

ip -6 route show default

Reading the result

You seeMeaning
Address starting with 2 or 3Global IPv6: you are good.
Only fe80::Link-local only: IPv6 is off on the router or not provided by the ISP.
fd… or fc…Private (ULA) address: the router uses IPv6 internally but has no internet IPv6.
Prefix length /64Standard LAN network: about 18.4 quintillion addresses for your proxies.

If you don't have IPv6

  1. Turn off any VPN and test again. Many VPNs disable IPv6 to prevent leaks.
  2. Check the router. Log in (often 192.168.1.1 or 192.168.0.1), find the IPv6 section, enable it on the WAN (DHCPv6, PPPoE IPv6 or "Auto", depending on the ISP) and choose SLAAC / Stateless / Auto for the LAN.
  3. Restart the router, then the computer.
  4. Ask the ISP. Some contracts need IPv6 enabled on their side; ask support for "IPv6 with a /64 on the LAN" or "prefix delegation".
  5. No luck? Use a VPS instead: nearly all of them include IPv6. See IPv6 proxies on a VPS.

A note on changing prefixes

Many home ISPs give you a dynamic prefix that can change after a modem restart. That is fine for proxies: openv6 notices the new prefix and moves every proxy to it while keeping its port, password and address suffix. If you need a prefix that never changes, ask the ISP for a static prefix or use a VPS.
