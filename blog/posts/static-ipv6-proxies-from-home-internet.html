Most people already pay for something that proxy companies sell: a residential IP. If your home connection has IPv6, it even comes with a whole /64 network, enough for a fixed address per account for the rest of your life. This guide shows how to turn it into static HTTP/SOCKS5 proxies.

What you need

  • A home internet connection with IPv6. Most large ISPs enable it today; check yours in two minutes.
  • One computer that stays on: a Windows 10/11 PC, a Mac, or a Linux box (Ubuntu, Debian, Zorin, a mini PC or a Raspberry Pi-class device).
  • Your anti-detect browser or any app that accepts HTTP or SOCKS5 proxies.

How it works

Your router gives every device on the LAN addresses from the same /64. openv6 adds one more address from that /64 to the machine for every proxy, and binds each proxy's outgoing connections to it:

Anti-detect profile ──IPv4──► 192.168.1.10:10001 (user/pass)
                               openv6 on your PC
                               └─ leaves from 2001:db8:51c0::a41f ──► website

Your apps connect over plain IPv4 on the LAN, so nothing else on your network needs to change.

Step 1: Install openv6

Download the installer for your system from the download section, or use the one-line installer:

# macOS / Linux (Terminal)
curl -fsSL https://raw.githubusercontent.com/thephux/openv6-releases/main/install.sh | sudo bash

# Windows (PowerShell as Administrator)
irm https://raw.githubusercontent.com/thephux/openv6-releases/main/install.ps1 | iex

openv6 runs as a background service, starts with the machine and puts an icon in the tray. The dashboard opens at http://127.0.0.1:8080; from another device use http://<machine-LAN-IP>:8080.

Step 2: Let it find your IPv6 prefix

On first start openv6 checks the network card, the IPv6 prefix and the default route, and tells you in plain words if something is missing (no IPv6 from the ISP, a VPN taking over the route, a firewall blocking ports). Most problems have a Fix button.

If the machine has both Ethernet and Wi-Fi, you can choose which one the proxies use.

Step 3: Create proxies

Go to Proxies → Create proxies and choose:

  • How many, and a name prefix such as FB (you get FB 01, FB 02, …).
  • Authentication: a random username and password per proxy is the safe default.
  • IPv4 fallback: leave it off for account work (see below).

Every proxy gets its own port, password and IPv6. The same port accepts both HTTP and SOCKS5.

Step 4: Check and export

Click Check all. openv6 asks an IP-echo service which address it sees through each proxy and compares it with the expected IPv6, so a green result means the website really sees that proxy's address. You also get the latency, country and ISP.

Then click Export and pick your anti-detect browser. openv6 has presets for Multilogin, GoLogin, Dolphin Anty, ixBrowser, Linken Sphere and AdsPower. More in our anti-detect setup guide.

Test one from any computer on the LAN:

curl -x http://USER:PASS@192.168.1.10:10001 https://api64.ipify.org
curl --socks5-hostname USER:PASS@192.168.1.10:10001 https://api64.ipify.org

Both should print the proxy's IPv6.

When your ISP changes the prefix

Home ISPs often rotate the prefix, for example after a power cut. openv6 stores each proxy as prefix + suffix, not as a full address. When the prefix changes, each proxy keeps its port, password and suffix and simply moves to the new prefix. Your profiles keep working; websites see a new address on the same ISP, which looks like a normal home reconnect.

If you need addresses that never change at all, use a VPS: see IPv6 proxies on a VPS.

Using the proxies outside your home

Many home connections are behind CGNAT, so you cannot open a port from the internet. openv6 offers three ways out:

MethodWhen to use
Relay through a VPSWorks everywhere, even behind CGNAT. The home machine connects out to a cheap VPS (encrypted); websites still see your home IPv6.
UPnPYour router has a public IPv4 and UPnP enabled.
TailscaleOnly your own devices need access.

Tips for account work

  • One profile, one proxy. Don't swap proxies between profiles.
  • Keep IPv4 fallback off for accounts: with it on, sites without IPv6 see your shared IPv4.
  • Same /64 = same household. All home proxies share your /64, so a platform may still group them. For stronger separation add a VPS with a /56 or /48; read /64 vs /56 vs /48.
  • Follow the rules of the platforms you use and of your ISP.
